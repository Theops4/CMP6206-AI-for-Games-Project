ANT WARS

2 rival ant factions fighting each other for survival 3 different types of ants each with a different AI. Worker ants going to collect food will use FSM, Soldier ants protecting the nest will use GOAP and the defending queen will use behaviour trees.

AI features: FSM, Behaviour trees and GOAP

Target game engine is unity 

Taking inspiration from real life ant colonies I aim to implement a pheromone system to alert other ants when a member of the colony finds something like a rival ant or food. 

Ant model used: "Walking Ant" (https://skfb.ly/oQ8sz) by kenchoo is licensed under Creative Commons Attribution-NonCommercial (http://creativecommons.org/licenses/by-nc/4.0/).
